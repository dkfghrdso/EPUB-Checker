# EPUB小说章节检查工具

这个工具可以检查指定目录中所有EPUB格式小说的前三章末尾内容，特别用于检查每章末尾是否包含指定的GitHub链接。

## 开发说明

本工具由AI辅助开发制作，基于Python语言实现，使用ebooklib和beautifulsoup4库解析EPUB文件。

## 功能特点

- 自动扫描指定目录中的所有EPUB文件
- 提取每个EPUB文件的前三章内容
- 检查每章末尾是否包含GitHub链接
- 对缺少链接的文件自动添加`[缺少链接]`前缀进行标注
- 如果文件已经被标注但现在符合要求，自动移除标注
- 显示每章的末尾部分（最后1000个字符）
- 支持批量处理多个EPUB文件

## 安装依赖

```bash
pip install ebooklib beautifulsoup4
```

## 使用方法

1. **准备工作**
   - 将需要检查的EPUB格式小说文件复制或粘贴到`test_books`文件夹中

2. **执行检查**
   - 直接运行以下命令即可开始检查：
   
   ```bash
   python epub_checker.py
   ```
   
   - 程序会自动检查`test_books`文件夹中的所有EPUB文件

## 输出说明

工具会为每个EPUB文件输出：
- 文件名
- 前三章的标题
- 每章末尾的1000个字符内容
- 章节总长度

## 注意事项

1. 章节排序基于HTML文件名的字母顺序，可能需要根据实际EPUB文件结构进行调整
2. 某些复杂的EPUB文件可能需要额外的解析逻辑
3. 工具仅检查前三章，如果文件不足三章，则检查所有可用章节
